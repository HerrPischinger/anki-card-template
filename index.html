Anki card template

Light and dark mode, an Important box, a Mnemonic box, a collapsible Bonus section, and a link button for URLs such as YouTube videos.

View on GitHub

Fields

FieldRequiredPurpose
VorderseiteyesFront of the card
RückseiteyesBack of the card
WichtignoRed "Important" box
EselsbrückenoBlue "Mnemonic" box
BonusnoCollapsible extra content
LinknoURL for the link button

Installation

  1. In Anki, open Tools → Manage Note Types, pick your note type, and add the fields above.
  2. Click Cards… and paste templates/front.html into the front template.
  3. Paste templates/back.html into the back template.
  4. Paste style.css into the styling tab.
